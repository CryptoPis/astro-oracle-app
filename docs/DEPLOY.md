# სერვერზე გაშვება: Neon + Render + cron-job.org

სულ დაახლოებით 30 წუთი. სამივე სერვისი უფასოა.

| სერვისი | რისთვის | გეგმა |
|---|---|---|
| **Neon** | მონაცემთა ბაზა (მომხმარებლები, ქოინები, სიზმრები) | Free |
| **Render** | სერვერი, სადაც აპლიკაცია და ბოტი მუშაობს | Free |
| **cron-job.org** | ა) სერვერს არ აძინებს; ბ) დილის ჰოროსკოპს 09:00-ზე აგზავნის | Free |

> ⚠️ **გასაღებები** (BOT_TOKEN, GROQ_API_KEY, DATABASE_URL) **მხოლოდ Render-ის ფორმაში ჩაწერე.**
> ჩატში, GitHub-ზე ან სხვაგან ნუ გააზიარებ. ეს Telegram-ის ჩათებსაც ეხება.

## 0. მოამზადე 3 რამ
1. **BOT_TOKEN:** Telegram → @BotFather → `/mybots` → @astrogm2026bot → **API Token**. ძველი ტოკენი უკვე შეცვლილია და ახალი გამოიყენე.
2. **GROQ_API_KEY:** https://console.groq.com/keys → **Create API Key**.
3. **შენი Telegram ID:** მისწერე @userinfobot-ს და ის ციფრებს გამოგიგზავნის, მაგ. `123456789`. ეს ADMIN_IDS-ში ჩაიწერება.

**AstroAPI გასაღები აღარ გვჭირდება.** კუნდლი და პლანეტების მდებარეობა ახლა თავად სერვერზე ითვლება, ზუსტად და უფასოდ.
ერთადერთი გარე AI სერვისი Groq-ია.

---

## 1. Neon: მონაცემთა ბაზა
1. გახსენი https://neon.tech → **Sign up** (უმარტივესია GitHub-ით).
2. **Create project**:
   - Name: `astro-oracle`
   - Postgres version: ნაგულისხმევი (default)
   - **Region: AWS Europe Central (Frankfurt)**, რადგან Render-იც ფრანკფურტშია და ასე ყველაზე სწრაფია.
3. პროექტის გვერდზე → **Connect** → ჩართე **Connection pooling** → დააკოპირე სტრიქონი. დაახლოებით ასეთია:
   `postgresql://neondb_owner:••••@ep-xxxx-pooler.eu-central-1.aws.neon.tech/neondb?sslmode=require`
4. შეინახე, ეს არის **DATABASE_URL**. სტრიქონს არაფერი შეუცვალო, აპლიკაცია მას თავად გარდაქმნის.

---

## 2. Render: სერვერი
1. გახსენი https://render.com → **Get Started** → **GitHub-ით შესვლა**.
2. GitHub-ის ნებართვის ფანჯარაში მიეცი წვდომა რეპოზიტორიაზე **CryptoPis/astro-oracle-app**.
3. Dashboard → **New +** → **Blueprint** → აირჩიე `astro-oracle-app`.
   Render თავად წაიკითხავს ფაილს `render.yaml` და ყველა პარამეტრს თავად დააყენებს.
4. გამოჩნდება 4 ცარიელი ველი. ჩაწერე:
   | ველი | რა ჩაწერო |
   |---|---|
   | `BOT_TOKEN` | ნაბიჯი 0.1 |
   | `GROQ_API_KEY` | ნაბიჯი 0.2 |
   | `DATABASE_URL` | Neon-ის სტრიქონი (ნაბიჯი 1.3) |
   | `ADMIN_IDS` | შენი Telegram ID (ნაბიჯი 0.3) |
5. **Apply**. პირველი აწყობა დაახლოებით 3-5 წუთს გრძელდება. ბოლოს ლოგში გამოჩნდება `Webhook set to https://...` და `Your service is live 🎉`.
6. დააკოპირე სერვისის მისამართი (ზემოთ წერია), მაგ.: `https://astro-oracle.onrender.com`.

ამის შემდეგ GitHub-ზე ყოველი ახალი ცვლილება Render-ზე ავტომატურად აიტვირთება.

---

## 3. BotFather: მინი აპლიკაციის რეგისტრაცია
1. @BotFather → `/mybots` → @astrogm2026bot → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → ჩასვი Render-ის მისამართი, ბოლოში `/`-ით:
   `https://astro-oracle.onrender.com/`
2. @BotFather → `/newapp` → აირჩიე @astrogm2026bot → სახელი: `Astro Oracle` → აღწერა → ფოტო (640×360, ლოგო) → GIF-ზე `/empty` →
   URL: იგივე მისამართი → **short name: `app`**.
   ამის შემდეგ იმუშავებს მეგობრის მოწვევის ბმულები: `t.me/astrogm2026bot/app?startapp=ref_...`
3. ბოტის მენიუს ღილაკს („🔮 Open“) სერვერი თავად აყენებს.

## 4. შემოწმება
1. ტელეგრამში გახსენი @astrogm2026bot → `/start` → **🔮 აპლიკაციის გახსნა**.
2. მისწერე ბოტს **`/diag`**. ეს ბრძანება მხოლოდ ადმინს უმუშავებს. ბოტი თითოეულ სისტემას შეამოწმებს და გიპასუხებს:
   ```
   ✅ BOT_TOKEN: set
   ✅ GROQ_API_KEY: set
   ✅ Database: connected in 12 ms, 1 users
   ✅ Telegram bot: @astrogm2026bot
   ✅ Webhook: 0 pending
   ✅ Groq text model: openai/gpt-oss-120b
   ✅ Groq test answer: 1.2 s: “Patience”
   🟢 All systems go
   ```
   თუ რომელიმე ხაზს ❌ უწერია, ეს ტექსტი გამომიგზავნე და მე გეტყვი, რა უნდა შეიცვალოს.

## 5. cron-job.org: სერვერის ფხიზლად ყოფნა და დილის ჰოროსკოპი
Render-ის უფასო სერვერს 15 წუთის უმოქმედობის შემდეგ ეძინება, ხოლო გაღვიძებას დაახლოებით 50 წამი სჭირდება. ამიტომ:

1. https://cron-job.org → **Sign up** → **Create cronjob**.
2. **Job 1: სერვერის ფხიზლად შენახვა**
   - Title: `astro keep-alive`
   - URL: `https://astro-oracle.onrender.com/healthz`
   - Schedule: **Every 10 minutes**
3. **Job 2: დილის ჰოროსკოპი**
   - Title: `astro morning`
   - URL: `https://astro-oracle.onrender.com/cron/morning?key=CRON_SECRET`
     **CRON_SECRET** აიღე Render → სერვისი → **Environment** → `CRON_SECRET` → 👁 (Render-მა ის თავად შექმნა).
   - Schedule: **Every day at 09:00**, Time zone: **Asia/Tbilisi**
   - ეს Job ყველა მომხმარებელს დილის ჰოროსკოპს უგზავნის და დღის ყველა ნიშნის ჰოროსკოპს წინასწარ ამზადებს, რომ აპლიკაციაში მყისიერად გაიხსნას.

---

## 6. ⚠️ ძველი ბოტის გათიშვა
თუ ძველი `main.py` სადმე ჯერ კიდევ მუშაობს (კომპიუტერზე, PythonAnywhere-ზე, VPS-ზე), **გათიშე**.
ერთ ტოკენზე ორი პროგრამა ერთმანეთს ხელს უშლის. ტოკენი ისედაც შეცვლილია, ამიტომ ძველი ასლი მაინც აღარ იმუშავებს.

## 7. (სურვილისამებრ) ძველი მომხმარებლების გადმოტანა
თუ ძველი `astro_bot.db` ფაილი შემოგრჩა, გამომიგზავნე. ბალანსებსა და დაბადების თარიღებს Neon-ში მე გადავიტან.

- **Neon Free:** 0.5 GB ბაზა, რაც ათიათასობით მომხმარებელს ყოფნის.
- **Groq Free:** დღიური და წუთობრივი ლიმიტები აქვს. თუ მომხმარებლები ბევრი გახდა და პასუხები ხანდახან აღარ მოვა, Groq-ის **Developer** გეგმაზე გადასვლაა საჭირო (გადახდა მოხმარების მიხედვით).
  აპლიკაცია ხარჯს ზოგავს: ჰოროსკოპი, ნუმეროლოგია, მთვარე და თავსებადობა ერთხელ იქმნება და ყველა იმავე ნიშნის მომხმარებელს ერთი პასუხი უჩანს.
- **როდის გადავიდეთ ფასიან გეგმაზე:** Render Starter ($7/თვე) საჭიროა, როცა ბევრი მომხმარებელი იქნება ან სრულიად „არაძინებადი“ სერვერი გინდა.
